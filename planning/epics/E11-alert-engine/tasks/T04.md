# T04 · Threshold rules engine

Epic: E11

## Expected
- model `AlertRule`: `id, alertType, sensorField, comparator (gt/lt/gte/lte), threshold Decimal, severity, isActive, ...`
- atom `flow/evaluate-rule.ts` — เรียกหลังรับ sensor message
- ถ้า value match rule → `createFromMqtt`
- ถ้า value กลับมา normal + active alert มี → resolve
- endpoint admin: `GET/POST/PATCH /api/alert-rules`
