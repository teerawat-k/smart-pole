# T07 · Backpressure + batch flush

Epic: E06

## Expected
- รวม sensor message ใน buffer 5 วินาที / 100 messages → flush เป็น batch ไป Influx
- ห้าม flush ทุก message (legacy ทำ → I/O สูง)
- ถ้า buffer เกิน 1000 → drop ตัวเก่าที่สุด + log warn + emit metric

## Test Guide
- [ ] 50 messages ใน 1s → 1 flush
- [ ] 1 message ใน 5s → flush ที่ 5s
- [ ] buffer overflow → drop + log
