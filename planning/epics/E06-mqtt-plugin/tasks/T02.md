# T02 · Topic dispatcher + Zod schema validation

Epic: E06

## Expected
- `src/plugins/mqtt/subscriber.ts`
  - subscribe `smartpole/+/sensor` (QoS 1), `smartpole/+/heartbeat` (QoS 0), `smartpole/+/alert` (QoS 2)
  - parse topic → `{ poleName, messageType }`
  - parse JSON payload → Zod schema → handler atom
  - validate fail → log warn `{ topic, payload, error }` + skip
  - handler throw → log error + ack + skip (ห้ามหยุด subscriber)
- `src/plugins/mqtt/schemas/`
  - `sensor.schema.ts` (Zod): `pole_id, timestamp, pm25, temperature, humidity, seq`
  - `heartbeat.schema.ts`: `pole_id, timestamp, status, signal_dbm, uptime_sec`
  - `alert.schema.ts`: `pole_id, timestamp, alert_type, value, threshold, message`
- timestamp drift > 5 min → reject

## Test Guide
- [ ] valid sensor message → handler called once
- [ ] invalid JSON → log + skip
- [ ] missing field → Zod error + log + skip
- [ ] handler throw → caught + log
- [ ] timestamp future > 5 min → reject
- [ ] mismatch poleName ใน topic vs payload → reject
