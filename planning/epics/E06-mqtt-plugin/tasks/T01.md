# T01 · MQTT client plugin — connect + reconnect + auth

Epic: E06

## Expected
- `src/plugins/mqtt/client.ts` — singleton `mqtt.MqttClient`
- ใช้ `mqtt` v5 npm package
- env: `MQTT_BROKER_URL`, `MQTT_USERNAME`, `MQTT_PASSWORD`, `MQTT_CLIENT_ID`
- options: `reconnectPeriod: 5000`, `connectTimeout: 10000`, `protocolVersion: 5`, `clean: false` (subscribe persistent)
- log: connect, reconnect, error, offline events
- export: `getMqttClient()`, `publish(topic, payload, opts)`, `disconnect()`

## Test Guide
- [ ] connect สำเร็จ → log "MQTT connected"
- [ ] broker down → reconnect every 5s
- [ ] auth ผิด → error log + retry
- [ ] disconnect ก่อน shutdown (graceful)
