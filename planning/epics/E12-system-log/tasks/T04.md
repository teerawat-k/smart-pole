# T04 · Page access tracking middleware

Epic: E12

## Expected
- `src/common/middleware/page-access.ts` — log SystemLog ทุกครั้งที่ user เข้าหน้าผ่าน frontend
- frontend ส่ง `POST /api/system-logs/page-access` body `{ pageKey }` ตอน route mount
- หรือ derive จาก first GET request ของ entity (เช่น `GET /api/poles` → page=`pole_monitor`)
