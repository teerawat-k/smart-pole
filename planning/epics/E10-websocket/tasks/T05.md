# T05 · Wire ทุก mutation → broadcast

Epic: E10

## Expected
- ทุก service method ที่ commit DB → call `sendInvalidate(stakeholderIds, entity)` หลัง commit
- pattern: `void invalidatePoleStakeholders(poleId)` ใน `shared/invalidate.ts` ของ module pole
- stakeholders = ผู้ใช้ที่มี permission `module:canView`
- คอนเซ็ปต์: เปลี่ยน entity ไหน → invalidate query key entity นั้น (frontend จะ refetch อัตโนมัติ)

## Test Guide
- [ ] create pole → user ที่ permission pole:canView → frontend list refetch
- [ ] user ที่ไม่มี permission → ไม่ได้รับ
