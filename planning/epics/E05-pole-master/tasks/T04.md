# T04 · Pole MQTT credential — generate + store hashed

Epic: E05

## Expected
- ตอน create pole → generate `mqttUsername` (= `mqtt-{poleName}`) + random 32-byte password → argon2 hash → save
- `POST /api/poles/:id/regenerate-mqtt-credential` (admin) — generate ใหม่
- response create/regenerate: return plain password ครั้งเดียว (ใส่ในเสา) — DB เก็บ hash เท่านั้น
- บันทึก `mqttCredentialIssuedAt`
