# T06 · Geolocation validation (lat/lng range)

Epic: E05

## Expected
- TypeBox schema: `latitude` -90..90, `longitude` -180..180, optional both หรือไม่มีเลย
- ห้ามมีแค่ lat ไม่มี lng (และกลับกัน)

## Test Guide
- [ ] lat=91 → validation error
- [ ] lng=181 → validation error
- [ ] มีแค่ lat → validation error
