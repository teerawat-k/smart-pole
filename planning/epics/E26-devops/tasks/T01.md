## Summary
- เขียน `docker-compose.yml` ครบ 4 services (mosquitto + srs + backend + frontend)
- Postgres ใช้ local install บน host (port 5432) — backend container ต่อผ่าน `host.docker.internal` (extra_hosts)
- TimescaleDB extension ติดตั้งใน Postgres host (`CREATE EXTENSION timescaledb`)
- เขียน `docker-compose.dev.yml` overlay เปิดเฉพาะ infra (mosquitto + srs)
- `.env.example` 3 ไฟล์ (root / backend / frontend) ตาม pattern pmk-psom-v2-remark
  - root → docker-compose ports + secrets
  - backend → app env + DATABASE_URL + MQTT + SRS
  - frontend → NEXT_PUBLIC_* เท่านั้น
- `infra/mosquitto/config/{mosquitto.conf,aclfile,passwordfile}` — anonymous dev / per-pole pattern ACL พร้อมใน production
- `infra/srs/srs.conf` — RTMP 1935 + HLS 8080 + DVR mp4 + http_hooks ไป backend
- สร้าง `data/` volume mount paths + ปรับ `.gitignore` ignore data/ ยกเว้น .gitkeep
