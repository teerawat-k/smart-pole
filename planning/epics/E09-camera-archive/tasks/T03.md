# T03 · SRS DVR callback endpoint

Epic: E09

## Expected
- `POST /api/srs/dvr` — รับ callback จาก SRS เมื่อ DVR file ปิด
- payload: `{ stream, file, duration, ... }` (ตาม SRS http_hooks spec)
- atom: parse stream → poleName → create VideoRecording row
- guard: shared secret header `X-SRS-Token` (env)
- file path: ตรวจว่ามีจริงใน volume (StorageProvider.exists) ก่อน save

## Test Guide
- [ ] callback → 1 row created
- [ ] missing token → 403
- [ ] file ไม่อยู่ใน MinIO → log warn + 200 (idempotent)
- [ ] duplicate filename → ignore (idempotent)
