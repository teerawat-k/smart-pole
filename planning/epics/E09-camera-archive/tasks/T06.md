# T06 · Soft delete + retention cron job

Epic: E09

## Expected
- `DELETE /api/recordings/:id` → soft delete (`deletedAt`, ไม่มี `isActive`)
- cron daily 02:00 — delete file จาก volume ที่ `deletedAt < now - 7 days` (StorageProvider.delete)
- cron daily 03:00 — auto soft-delete recordings เก่ากว่า retention (config DB key `recording.retention_days`, default 90)

## Test Guide
- [ ] soft delete → ไม่อยู่ใน list, file ยังอยู่
- [ ] หลัง 7 วัน → file ลบจริง
- [ ] retention auto-delete ทำงาน
