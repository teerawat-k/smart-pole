# T04 · Signed URL generator (JWT)

Epic: E09

## Expected
- service method `getPlaybackUrl(recordingId, userId)` → `{ url, expiresAt }`
- token = JWT short-lived (1 hr) payload `{ sub: userId, recId, exp }`
- url = `${API_BASE}/recordings/{storagePath}?token=<jwt>`
- audit log: `RECORDING_PLAYBACK` with `recordingId`
- ตรวจว่า user มี `camera_archive:canView`
- Static plugin middleware verify JWT + match recId กับ path

## Test Guide
- [ ] token valid → stream OK
- [ ] หลัง 1 hr → 401
- [ ] token recId mismatch path → 403
- [ ] audit log บันทึกทุกครั้ง
