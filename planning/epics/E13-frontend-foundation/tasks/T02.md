# T02 · env + axios client + interceptor

Epic: E13

## Expected
- `config/env.ts` — Zod validate `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_WS_URL`, `NEXT_PUBLIC_PROJECT_PREFIX`
- `lib/api/client.ts` — Axios instance
- request interceptor: attach `Authorization: Bearer ${accessToken}` จาก auth store
- response interceptor: 401 → refresh → retry; refresh fail → logout + redirect /login
- error normalization: throw `Error(message)` ใช้ `error.error.message` จาก backend

## Test Guide
- [ ] valid request → ส่ง token
- [ ] expired access → refresh + retry transparently
- [ ] refresh fail → logout
- [ ] error message ภาษาไทยถูก
