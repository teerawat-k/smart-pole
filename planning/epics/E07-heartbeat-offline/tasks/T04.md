# T04 · Auto-create offline alert

Epic: E07

## Expected
- เมื่อ pole offline จาก scan → `alertService.create({ alertType: 'pole_offline', severity: 'warning' })`
- เมื่อ pole online (จาก heartbeat) + มี active offline alert → `alertService.resolve(alertId, { resolvedBy: SYSTEM_USER_ID })`

## Test Guide
- [ ] offline → 1 alert active
- [ ] online → alert resolved automatically
- [ ] ไม่สร้าง alert ซ้ำ (1 active per pole)
