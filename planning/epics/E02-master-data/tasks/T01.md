## Notes
- `UserStatus.locked` คนละกับ `lockedUntil` — locked = admin ตั้ง permanent (ห้าม login), lockedUntil = soft lock จาก fail count (auto-unlock เมื่อหมด)
- legacy ใช้ bcrypt password — ของเราใช้ argon2id (E01 มี fallback verify bcrypt + re-hash ตอน login สำเร็จ)
