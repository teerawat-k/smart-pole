# T02 · User module — CRUD + lookup + pagination

Epic: E04

## Expected
- `src/modules/user/` ตาม pattern
- Endpoints:
  - `GET /api/users?page&limit&search&sortBy&sortOrder&roleId&isActive`
  - `GET /api/users/lookup` (id+fullName)
  - `GET /api/users/:id`
  - `POST /api/users` (admin create — ส่ง password)
  - `PATCH /api/users/:id` (admin edit)
  - `DELETE /api/users/:id` (soft)
- SELECTs แยก list (มี role.displayName) / detail (มี role + lockedUntil) / lookup (id, fullName)
- list pagination + search by 4 fields (`OR: [username, email, firstName, lastName].contains`)
- ห้าม return `passwordHash`
