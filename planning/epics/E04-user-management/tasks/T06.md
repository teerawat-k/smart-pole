# T06 · My profile — `/me`, `/me/password`, `/me/sessions`

Epic: E04

## Expected
- `GET /api/me` — โปรไฟล์ตัวเอง
- `PATCH /api/me` — แก้ firstName/lastName/mobileNo/email (ห้ามแก้ username/role)
- `PATCH /api/me/password` body `{ currentPassword, newPassword }`
  - verify current → hash new → save → trigger logout-all
- `GET /api/me/sessions` — list refresh token active
- `DELETE /api/me/sessions/:id` — revoke 1 session

## Test Guide
- [ ] /me return ข้อมูลตัวเอง (ไม่มี passwordHash)
- [ ] change password ผิด current → 400
- [ ] change password new < 8 char → validation error
- [ ] /me/sessions ไม่เห็น session ของ user อื่น
