# T03 · `/users/:id/status` — toggle active + reset lockout

Epic: E04

## Expected
- `PATCH /api/users/:id/status` body `{ isActive: boolean }`
- ถ้า isActive=true → reset `loginFailCount=0, lockedUntil=null, lockedReason=null`
- ห้าม disable ตัวเอง (`request.userId === target.id`)
- ห้าม disable last admin (จะไม่มี admin ในระบบ)

## Test Guide
- [ ] disable → user login ไม่ได้
- [ ] enable → login ได้ + lockout reset
- [ ] disable ตัวเอง → 403
- [ ] disable admin คนสุดท้าย → 403
