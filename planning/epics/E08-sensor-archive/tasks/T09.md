# T09 · Retention policy per sensor (DB-backed config)

Epic: E08

## Expected
- ทุก `SensorType.retentionDays` driven retention policy
- สามารถ tune per sensor (เช่น `pm25=730 วัน, humidity=180 วัน`)
- เมื่อ admin เปลี่ยน retention → service emit job สั่ง `add_retention_policy` หรือ `remove_retention_policy + add_retention_policy` ใหม่
- Aggregates retention:
  - 5min view → retentionDays / 4 (default 90)
  - 1h view → retentionDays × 2 (default 730)
  - 1d view → retentionDays × 5 (default 1825)

## Test Guide
- [ ] update retentionDays → policy เปลี่ยน
- [ ] data > retention → auto-deleted
- [ ] aggregate ยังอยู่ตาม policy ของ aggregate
