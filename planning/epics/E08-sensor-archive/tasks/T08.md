# T08 · Continuous aggregates per sensor

Epic: E08

## Expected
- ทุก sensor table มี continuous aggregates 3 ระดับ: 5min, 1h, 1d
- Pattern (per sensor):
  ```sql
  CREATE MATERIALIZED VIEW sensor_pm25_5min
  WITH (timescaledb.continuous) AS
  SELECT time_bucket('5 minutes', time) AS bucket, pole_id,
         avg(pm25) AS pm25_avg, max(pm25) AS pm25_max, min(pm25) AS pm25_min,
         avg(pm10) AS pm10_avg, count(*) AS samples
  FROM sensor_pm25 GROUP BY bucket, pole_id;

  SELECT add_continuous_aggregate_policy('sensor_pm25_5min',
    start_offset => INTERVAL '1 day', end_offset => INTERVAL '5 minutes',
    schedule_interval => INTERVAL '5 minutes');
  ```
- helper `addContinuousAggregateSql(...)` (T01) ลด boilerplate
- service flow `get-aggregate.ts` เลือก view ตาม interval param
