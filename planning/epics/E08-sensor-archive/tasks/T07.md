# T07 · Sensor handler registry — dispatch ตาม sensor type

Epic: E08

## Expected
- `src/plugins/mqtt/handlers/handle-sensor.ts` (override จาก E06.T03):
  - parse `payload.readings: { [sensorKey]: { ... } }`
  - iterate keys → `getSensorHandler(key)` → ถ้ามี: validate Zod + write
  - key ที่ไม่มี handler → log warn + insert `SensorUnknown` row (raw JSON, สำหรับ admin debug)
  - validate fail → log warn + skip
- error 1 sensor key ไม่ block sensor key อื่นใน message เดียวกัน
- `flow/dispatch-readings.ts` atom — testable แยก
- model `SensorUnknown`:
  ```prisma
  time      DateTime
  poleId    Int
  sensorKey String
  rawJson   Json
  reason    String   // "no_handler" | "validation_failed"
  @@id([time, poleId, sensorKey])
  @@index([sensorKey, time(sort: Desc)])
  ```

## Test Guide
- [ ] payload มี 3 sensors (pm25/temp/humidity) → 3 writes
- [ ] payload มี 1 unknown sensor → log warn + insert sensor_unknown
- [ ] validation fail 1 sensor → อีก 2 ผ่าน
