# T02 · Auth module — login flow + lockout policy

Epic: E01
Status: todo
Blocked by: E00,E01.T01

## Expected
- `src/modules/auth/` ตาม atomic pattern
  - `auth.controller.ts` — `POST /api/auth/login` body `{ username, password, sessionKey, captchaInput }`
  - `auth.service.ts` — orchestrator (delegate flow/)
  - `flow/find-user.ts` — atom: find by username + role
  - `flow/check-active.ts` — atom: check `user.isActive`
  - `flow/check-locked.ts` — atom: check `user.lockedUntil`
  - `flow/verify-password.ts` — atom: argon2 verify (+ legacy bcrypt fallback + auto re-hash)
  - `flow/handle-fail.ts` — atom: increment fail count + apply lockout policy
  - `flow/handle-success.ts` — atom: reset fail count + update lastLoginAt + log
  - `flow/issue-tokens.ts` — atom: generate access + refresh (delegate T03)

## Lockout Policy (atom `apply-lockout.ts`)
```
fail 1-3  → ไม่ lock
fail 4-6  → lockedUntil = now + 10 min
fail 7-9  → lockedUntil = now + 30 min
fail ≥10  → isActive = false, lockedReason = "too_many_attempts"
```

## API Response
- success: `{ success, data: { user, accessToken, refreshToken } }`
- locked: 401 `{ code: "AUTH-LOCKED", message: "บัญชีถูกล็อก กรุณาลองใหม่ใน X นาที", remainingMinutes }`
- invalid: 401 `{ code: "AUTH-INVALID", message: "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง" }`

## Test Guide
- [ ] login ถูก → 200 + token
- [ ] password ผิด 3 ครั้ง → fail count = 3 ไม่ lock
- [ ] ครั้งที่ 4 → lockedUntil = now+10min
- [ ] ครั้งที่ 7 → lockedUntil = now+30min
- [ ] ครั้งที่ 10 → isActive=false
- [ ] login ขณะ lock → 401 พร้อม remainingMinutes
- [ ] captcha ผิด → 400 (ก่อน verify password — กัน brute force)
- [ ] login user ที่เป็น bcrypt hash → verify ผ่าน + DB update เป็น argon2
