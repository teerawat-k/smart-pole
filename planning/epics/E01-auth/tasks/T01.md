# T01 · Captcha module — image render + session table + verify

Epic: E01
Status: todo
Blocked by: E00

## Expected
- Prisma model `CaptchaAttempt`: `id, sessionKey, captchaTextHash, isSolved, createdAt, expiresAt` (5 min TTL)
- `src/modules/captcha/` ตาม atomic pattern
  - `captcha.controller.ts` — `GET /api/captcha/new` → `{ sessionKey, image (base64 PNG) }`
  - `captcha.service.ts` — `create()` + `verify(sessionKey, input)`
  - `flow/render-image.ts` — atom: text → PNG buffer (canvas / svg)
  - `flow/cleanup-expired.ts` — cron job ลบ captcha หมดอายุ
- เก็บ **hash** ของ captcha text (ไม่ plain) — เผื่อ DB leak
- รหัส 6 ตัว, mix ตัวอักษร + ตัวเลข (ยกเว้น 0/O/I/l)

## API
- `GET /api/captcha/new` → `{ sessionKey, image: "data:image/png;base64,..." }`
- `verify` ภายใน — ใช้ใน `auth.service.login`

## Test Guide
- [ ] generate → return base64 PNG ขนาด ≥ 100x40
- [ ] verify ถูก → mark solved
- [ ] verify ผิด → false (ไม่ mark solved → ลองใหม่ได้)
- [ ] verify หลังหมดอายุ → false
- [ ] integration: cleanup job ลบ expired ทุก 1 ชม.

## Notes
- ใช้ `sharp` หรือ `node-canvas` หรือ pure-svg — เลือกที่ build บน Bun ได้
- ห้าม return text ตรง (legacy ทำผิด)
