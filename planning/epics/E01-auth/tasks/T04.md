# T04 · Logout + refresh-token endpoint + token blacklist

Epic: E01
Status: todo
Blocked by: E01.T03

## Expected
- `POST /api/auth/logout` — รับ refreshToken → revoke (set `revokedAt`)
- `POST /api/auth/logout-all` — revoke ทุก refresh token ของ user (เปลี่ยน password ก็เรียก)
- Access token: ไม่ blacklist (sho-lived 15m) — ปล่อยให้หมดอายุเอง
- (Optional) `POST /api/auth/sessions` — list refresh tokens active ของตัวเอง + revoke เฉพาะ session

## Test Guide
- [ ] logout → refresh นั้น revoke แล้ว ใช้ไม่ได้
- [ ] logout-all → ทุก refresh ของ user revoke
- [ ] เปลี่ยน password → trigger logout-all อัตโนมัติ
- [ ] audit log มี action `LOGOUT`

## Notes
- เผื่อต้องบังคับ logout ทุก device หลัง security incident
