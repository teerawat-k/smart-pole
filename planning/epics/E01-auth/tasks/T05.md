# T05 · Auth middleware — verify access token + derive userId/role + rate limit

Epic: E01
Status: todo
Blocked by: E01.T03

## Expected
- `src/plugins/auth.ts` — Elysia plugin (scoped derive)
  - extract bearer → verify → throw `AUTH-FORBIDDEN` ถ้า invalid
  - derive `{ userId, role, requestId }` ให้ทุก handler ใช้
- `src/common/middleware/rate-limit.ts` — Elysia plugin
  - `POST /auth/login` + `/auth/refresh`: 10 req/min per IP
  - mutation: 60 req/min per user
  - GET: 200 req/min per user
  - 429 + `Retry-After` header
- ใช้ in-memory token bucket (เผื่อ scale-out → ย้าย Redis ใน phase 2)

## Test Guide
- [ ] missing bearer → 403 `AUTH-FORBIDDEN`
- [ ] expired access → 401 `AUTH-TOKEN-EXPIRED`
- [ ] valid → derive userId/role ใช้ใน handler ได้
- [ ] login 11 ครั้งใน 1 นาที → ครั้งที่ 11 = 429
- [ ] mutation 61 ครั้ง/นาที per user → 429

## Notes
- **GET /auth/captcha + POST /auth/login** = public (ก่อน auth middleware)
- ตำแหน่งใน Elysia: `.use(rateLimit).use(auth)` แล้วค่อย `.use(<protectedController>)`
