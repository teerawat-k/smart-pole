# T07 · Login attempt log (system_log entries)

Epic: E01
Status: todo
Blocked by: E01.T02

## Expected
- ทุก login event เขียน `SystemLog` entry
  - logType: `login_success` | `login_fail`
  - usernameSnap (snapshot — แม้ user ไม่มี)
  - failReason: `user_not_found`, `account_disabled`, `account_locked`, `wrong_password`, `wrong_captcha`
  - ipAddress, userAgent
- แยกจาก `AuditLog` (E00.T07) — auth log มี frequency สูง + retention policy ต่างกัน

## Test Guide
- [ ] login สำเร็จ → 1 entry login_success
- [ ] login fail user ไม่มี → 1 entry login_fail with reason `user_not_found` (userId null)
- [ ] login fail captcha → 1 entry with reason `wrong_captcha`
- [ ] ipAddress + userAgent บันทึกครบ

## Notes
- IP จาก `x-forwarded-for` (ถ้ามี proxy) → fallback `request.ip`
- userAgent จาก header
