# T03 · JWT plugin — access (15m) + refresh (7d) + rotation

Epic: E01
Status: todo
Blocked by: E00

## Expected
- `src/plugins/jwt.ts` — Elysia plugin wrap `@elysiajs/jwt` + sign helpers
- Access token: payload `{ sub, role, iat, exp }`, expiry 15m
- Refresh token: random 32-byte hex, SHA-256 hash → DB
- Prisma model `RefreshToken`: `id, userId, tokenHash, family (uuid), issuedAt, expiresAt, revokedAt?, replacedById?`
- Atom helpers in `src/modules/auth/flow/issue-tokens.ts`
- Rotation: ใช้ refresh → ออก access ใหม่ + refresh ใหม่ + revoke เก่า + link `replacedById`

## Reuse Detection
- ใช้ refresh token ที่ revoked แล้ว → invalidate ทั้ง family + force user logout

## API
- `POST /api/auth/refresh` body `{ refreshToken }` → `{ accessToken, refreshToken }`

## Test Guide
- [ ] sign + verify access token
- [ ] expired access → 401 code `AUTH-TOKEN-EXPIRED`
- [ ] refresh → ได้ access ใหม่ + refresh ใหม่
- [ ] ใช้ refresh เก่าซ้ำหลัง rotate → revoke ทั้ง family
- [ ] refresh หมดอายุ → 401
