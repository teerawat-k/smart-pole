# T10 · Module template script — `bun scripts/new-module.ts <name>`

Epic: E00
Status: todo
Blocked by: T04,T07

## Expected
- `backend/scripts/new-module.ts` — รับชื่อ module (kebab-case) → generate folder + 7 ไฟล์ตาม pattern
- Generate:
  - `<name>.controller.ts` (with `/`, `/lookup`, `/:id`, POST, PATCH, DELETE skeleton + auth + requirePermission)
  - `<name>.service.ts` (orchestrator delegate flow/ — เริ่มแบบ inline ก่อน)
  - `<name>.repository.ts` (with `LIST_SELECT`, `DETAIL_SELECT`, `LOOKUP_SELECT` skeletons)
  - `<name>.schema.ts` (TypeBox)
  - `<name>.constants.ts` (`<NAME>_ENTITY`, `<NAME>_QUERY_KEY`, `<Name>NotificationType`)
  - `<name>.service.test.ts` (sample test with mock.module)
  - `index.ts` (export controller + service)
- Auto append `import { <name>Controller } from "./modules/<name>"` + `.use(<name>Controller)` ใน `src/index.ts`
