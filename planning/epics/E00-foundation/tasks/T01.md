## Expected
- ติดตั้ง Bun + Elysia + dependencies (`@elysiajs/cors`, `swagger`, `static`, `jwt`, `bearer`)
- `src/config/env.ts` — Zod validate ทุก env (`PORT`, `DATABASE_URL`, `JWT_SECRET`, `CORS_ORIGIN`, `LOG_LEVEL`, MQTT/Influx/MinIO ที่จะเพิ่มต่อ)
- `src/index.ts` — Elysia app + cors + swagger + static + onError handler
- `GET /health` (liveness) + `GET /health/ready` (readiness — ตรวจ DB connect)
- Graceful shutdown: SIGTERM → drain 30s → close → exit
- `package.json` scripts: `dev`, `start`, `kill-port`, `setup`

## API
- `GET /health` → `{ success: true, data: { status: "ok" } }`
- `GET /health/ready` → `{ success: true, data: { db: "ok" } }` หรือ 503 ถ้า DB down

## Test Guide

- [ ] หยุด DB → `curl /health/ready` → 503
