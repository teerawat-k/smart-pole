## Expected
- `src/plugins/logger.ts` — Pino instance (production: JSON, dev: pino-pretty) + redact secrets
- `src/common/middleware/request-id.ts` — Elysia plugin
  - generate UUID v4 ที่ `onRequest` → `store.requestId`
  - attach `X-Request-Id` header ทุก response
  - log: `{ requestId, method, path, statusCode, duration }`
- error response มี field `requestId`

## Summary
- เพิ่ม `redact` paths ใน Pino: password / token / secret / passwordHash → `***`
- timestamp: ISO 8601 format
- request-id plugin ใช้ `onRequest` (run ก่อน routing) → ครอบ NOT_FOUND ได้
- รับ x-request-id จาก client (ถ้า match `[\w-]{8,128}`) — fallback UUID v4
- expose `x-request-id` ใน CORS allowed headers
- onError ใช้ `store.requestId` ใส่ใน response + log context
