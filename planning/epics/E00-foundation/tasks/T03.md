# T03 · Logger plugin — Pino structured + request id middleware

Epic: E00
Status: todo
Blocked by: T01

## Expected
- `src/plugins/logger.ts` — Pino instance (production: JSON, dev: pino-pretty)
- `src/common/middleware/request-id.ts` — Elysia plugin
  - generate UUID v4 ที่ `onRequest` → `request.id`
  - attach `X-Request-Id` header ในทุก response
  - log: `{ requestId, method, path, statusCode, duration, userId? }`
- เก็บ requestId ลง error response เพื่อ frontend toast แสดง

## Test Guide
- [ ] ส่ง request → response มี header `X-Request-Id`
- [ ] log ออกมาเป็น JSON ใน production mode
- [ ] error response มี field `requestId`
- [ ] ห้าม log password/token (test กับ field ที่มี `password` ใน body)

## Notes
- ห้าม log body ทั้งก้อน — log แค่ method + path + statusCode + duration
- ใช้ AsyncLocalStorage เพื่อแชร์ requestId ระหว่าง handler chain (เผื่อ logger ใน service ต้อง trace)
