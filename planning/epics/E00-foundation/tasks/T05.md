## Summary
- ใช้ TypeBox (Elysia's `t`) ทุก schema — ไม่ใช้ Zod ใน HTTP layer (ตามมาตรฐาน Elysia type inference)
- pagination: `page/limit/search/sortBy/sortOrder` — spread เข้า `t.Object()` ของ list endpoint
- reorder: `id + order ≥ 0`
- password: `≥ 8 chars + ต้องมีตัวอักษร + ต้องมีตัวเลข` (regex `^(?=.*[A-Za-z])(?=.*\d).{8,}$`)
- helper `isPasswordConfirmed()` สำหรับ check confirm match (ใน service)
- ปรับ `utils/pagination.ts` ให้ใช้ `PaginationParams` type ใหม่
