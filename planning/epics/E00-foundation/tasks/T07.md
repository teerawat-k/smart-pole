## Expected
- `src/modules/audit/` — module ปกติตาม atomic pattern
  - `audit.repository.ts` — `create(input, tx?)`
  - `audit.service.ts` — `log({ userId, action, targetType, targetId, detail? })` fire-and-forget
  - `audit.constants.ts` — `AuditAction` constant (`CREATE`, `UPDATE`, `DELETE`, `TOGGLE_ACTIVE`, `REORDER`, `LOGIN`, `LOGOUT`, `MQTT_INGEST`, ...)
- Prisma model `AuditLog` — แยกจาก `SystemLog` (login/page-access)
  - fields: `id, userId, action, targetType, targetId, detail Json, ipAddress, requestId, createdAt`

## Test Guide
- [ ] `auditService.log(...)` ไม่ throw แม้ DB error (catch ภายใน + log warn)
- [ ] `await auditService.log(...)` ไม่ block — return immediately (Promise resolved ใน next tick)
- [ ] integration test: 1 log entry per call
- [ ] mutation อื่นเรียก audit ไม่ได้รอ — เร็วเท่าไม่มี audit (test ด้วย benchmark < 1ms overhead)

## Notes
- **ห้าม await** ใน caller — `void auditService.log(...)`
- ใช้ใน `service` layer เท่านั้น — ห้ามใน `controller` หรือ `repository`
